# 使用指南

## 推荐入口

每次新任务都从总导演开始：

```text
使用 minimax-h3-creative-director 帮我制作 MiniMax H3 视频提示词。
```

然后提供你已经确定的信息，例如：

- 视频时长与画幅；
- 人物、物品或环境；
- 上传素材分别承担什么作用；
- 故事动作、情绪变化和结尾；
- 是否多镜头；
- 对白、环境声、拟音和音乐要求。

信息不足时，总导演会提供结构化选项。严格的是非题可以有2个选项，其他选择题至少有5个选项，也可以直接输入自定义答案。

## 参考图片

如果图片用于保持人物、服装、物品、场景或风格一致性，不需要把它描述成“纯首帧”。总导演会默认采用参考一致性流程，并允许通过提示词同时规定开场画面或结尾画面。

只有以下类型的需求才使用纯关键帧模式：

```text
这两张图片只分别作为第一帧和最后一帧，不需要参考其中人物、物品、服装或风格的一致性。
```

## 多镜头

明确告诉总导演视频时长和是否需要多镜头：

```text
制作一个12秒、三个镜头的视频，请逐镜头询问并让我分别确认。
```

不要在镜头尚未确认时要求直接输出最终提示词；规划完成后，总导演会自动把镜头计划交给正确的格式化 Skill。

## 审查已有提示词

```text
使用 minimax-h3-creative-director 和 minimax-h3-prompt-reviewer 检查下面的提示词，修复结构、时间线、运镜和声音问题。
```

Reviewer 默认输出修复后的英文 H3 提示词，并附带中文说明或翻译。
